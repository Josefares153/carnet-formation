# Carnet de formation

Suivi personnel de cours en ligne (Coursera, edX), des conférences auxquelles je participe, et prise de notes manuscrites rattachées à chaque cours (stylo à pression, surligneur, gomme, texte, export PDF).

Site statique en un seul fichier (`index.html`). Les données restent dans le navigateur (localStorage + IndexedDB) ; l'export JSON sert de sauvegarde.
